# Guaribas Limpo

MVP estático para demonstrar o fluxo **mapear -> conectar -> medir**.

## Executar localmente

Abra `index.html` no navegador. O mapa usa Leaflet e OpenStreetMap via CDN, portanto precisa de conexão com a internet para carregar os tiles.

## Estrutura

- `index.html`: estrutura das três abas.
- `src/styles.css`: estilos responsivos.
- `src/app.js`: dados demonstrativos e interações.

Os dados são fictícios. A integração com concessionária, Prefeitura e Tarifa Social deve ser feita somente após validação institucional.
